Each guide answers one question from start to finish: the search, what to read from the results, and the
table or library you end up with. The [Usage]({{< ref "usage" >}}) pages explain one feature at a time; the
guides combine them.

Most of these questions are hard to ask with the `ads` package. Each needs something SciX's query language
does not have: a condition about one particular author, the country or the parent of an institution, the
narrower terms of a concept, or the contents of a library.

| Guide | Question |
|---|---|
| [Collaborations by country]({{< ref "guides/collaborations-by-country" >}}) | Which co-authors have I had abroad, and in which countries? |
| [A collaborators table]({{< ref "guides/collaborators-table" >}}) | Who have I published with recently, where were they, and when? |
| [One author among namesakes]({{< ref "guides/one-author-among-namesakes" >}}) | Which papers are by this person, and not by someone else of the same name? |
| [Papers to claim on ORCID]({{< ref "guides/papers-to-claim-on-orcid" >}}) | Which of my papers do not carry my ORCID iD yet? |
| [An author's affiliation history]({{< ref "guides/affiliation-history" >}}) | Where has this person worked, and when? |
| [Referees without a conflict of interest]({{< ref "guides/referees-without-conflicts" >}}) | Who is active on this topic and has no tie to me? |
| [An institution's output]({{< ref "guides/institution-output" >}}) | What did we publish, how much did we lead, and with whom? |
| [What a reading list is missing]({{< ref "guides/reading-list-gaps" >}}) | What do the papers in my library cite that I have not collected? |
| [A weekly reading list by topic]({{< ref "guides/weekly-reading-list" >}}) | What is new on my topic since I last looked? |
| [Literature for a landing site]({{< ref "guides/landing-site-literature" >}}) | What has been written about these places on Mars? |

The examples run against the small offline sample of papers used throughout this site, so the lists they
print are short. Against SciX the same code returns everything that matches.
